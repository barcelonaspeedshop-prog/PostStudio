# Channel set-up (20 Oct 2026)

What to paste into YouTube Studio for Gentlemen of Fuel, Omnira F1 and Omnira Football. Read from the live channels today: none has keywords, GoF's country is Spain and the other two have none, and the descriptions are the old ones (GoF "no commentary… engine sounds", Football "Omnira FC").

**Where things go in YouTube Studio:**
- **Description:** Customisation › Profile › Description
- **Keywords and country:** Settings › Channel › Basic info
- **Audience:** Settings › Channel › Advanced settings
- **Upload defaults:** Settings › Upload defaults
- **Home page:** Customisation › Layout
- **Playlists:** Content › Playlists. To add many videos at once: Content › Shorts (or Videos), tick the boxes, then Add to playlist.

## 4. Same on all three channels

**Audience** (Settings › Channel › Advanced settings): "No, set this channel as not made for kids".

**Upload defaults** (Settings › Upload defaults; this saves setting them on every upload):
- **Title, description, tags:** leave blank. They come from each upload pack.
- **Visibility:** Private. You schedule each video yourself.
- **Category:** as above (GoF Autos & Vehicles; F1 and Football Sports).
- **Video language and title/description language:** English (United Kingdom).
- **Caption certification:** "This content has never aired on television in the US".
- **Comments:** On, "Hold potentially inappropriate comments for review".
- **Altered or synthetic content:** set it to Yes if the box is offered here. If it isn't, it stays a tick on every upload; every upload pack lists it.
